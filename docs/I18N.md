# Internationalization status

`I18N-Standard: Applies — deferred to the 1.0 milestone. Reviewed 2026-07-05.`

## Why this applies

`reconcile review` renders a civic, user-facing web UI (`review/render.py`) for
non-technical caseworkers and volunteers, and the README (`## Usage`) commits
this project to "English and Spanish at parity for public-facing copy." Both
independently bring the repo into the standard's scope regardless of the
standard's own repo list (which predates this repo — see
`docs/RESPONSIBLE-TECH-AUDITS.md`).

## Current state

* All UI and CLI user-facing strings are hardcoded English literals. There is
  no `locales/` directory, no `gettext`/`babel` catalog, and no extraction
  tooling wired up yet.
* `<html lang="en">` is set correctly on every rendered review page
  (`review/render.py`), and the only authored BCP 47 tag (`en`) is valid.
* Files are UTF-8/ASCII throughout; no CI gate asserts this yet.

## Why it is deferred, not dropped

Catalog infrastructure and a reviewed Spanish translation are real work
(extraction, a translation workflow, and a native or fluent reviewer for the
ES copy — not machine translation of caseworker-facing decision language).
Building it before the review UI's own structure and copy stabilize would mean
re-translating churn. The commitment stays; the sequencing follows the
project's own phase discipline (ship the differentiator, then widen).

## Plan

1. **Before the 1.0 tag:** extract every hardcoded string in `review/render.py`
   and the CLI's user-facing output into a `pybabel`/gettext catalog
   (`locales/en/LC_MESSAGES/`), with a CI gate asserting key/placeholder parity
   across catalogs (I18N-04, the AUTO half of the ledger's i18n row).
2. **Same milestone:** commission or write a reviewed Spanish translation
   (`locales/es/`), with a named reviewer (not machine translation, given the
   sensitivity of DV/caseworker-facing language) and a plain-language check
   matching the English copy's Grade ≤8 reading-level bar.
3. Track both as the `docs/ROADMAP.md` metrics ledger's "i18n parity (EN, ES)"
   row, gated AUTO once the catalog exists.
