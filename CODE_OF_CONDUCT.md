# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

In short: participate respectfully. Harassment, discrimination, and personal
attacks are not welcome. Given the populations this tool serves, contributors are
also expected to treat privacy and safety as first-order concerns, not
afterthoughts.

To report unacceptable behavior, contact the maintainer by email. Reports are
handled confidentially.

The full text of the Contributor Covenant 2.1 is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
